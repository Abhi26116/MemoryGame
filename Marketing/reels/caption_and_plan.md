# Memory Match — Reel v1

**Full cut:** `Marketing/reels/memory_match_reel_v1.mp4` (1080×1920, 21.9s, 30fps, silent)
**Short cut:** `Marketing/reels/memory_match_reel_12s.mp4` (1080×1920, 12.0s, 30fps, silent)
**Cover:** `Marketing/reels/reel_cover.jpg`
**Rebuild:** `bash Marketing/reels/_build/make_reel.sh all` (or `12` / `v1` for one cut)

The 12s cut keeps memorize → flip → quiz → final matches → win → CTA and drops
the middle of the gameplay montage. Post both and compare retention: the short
one usually wins on completion rate, the long one sells the app harder.

Audio is intentionally silent — add a trending sound inside Instagram so the reel
gets picked up by that sound's feed.

Look: candy-bright animated background, thick-outlined sticker type that pops in
with an overshoot, a depleting countdown ring over the memorise beat, a white
flash plus confetti burst on the win, and a CTA whose elements pop in one by one.
To change the wording or beat timings, edit `timeline()` in `_build/reel2.py`;
to change colours or type, edit `_build/style2.py`.

**Answer to the quiz in the reel:** both 🌈 are in column 3 — row 1 and row 3.
Pin this as your own first comment a few hours after posting.

## Posting plan

1. **Cross-post the same file** to Instagram Reels, TikTok, YouTube Shorts and
   Facebook Reels. Same video works on all four (9:16, under 60s).
2. **Trending audio**: pick one in-app with 5k–50k uses (not 2M+ — too crowded).
   Set it to ~15% volume if you don't want it loud over the visuals.
3. **Reply to every comment in the first hour.** The quiz format is built to
   pull comments; replies multiply reach.
4. **Pin the answer** as a comment after a few hours ("both rainbows — column 3,
   rows 1 and 3 👀 did you get it?").
5. **Post 1–2× per day for two weeks with different hooks.** One reel almost
   never breaks out; testing hooks is what finds the winner. Keep whichever
   first-second text holds the most viewers and rebuild around it.
6. **Bio link**: Instagram doesn't allow links in reel captions, so the bio link
   is correct. Also add a link sticker when you reshare the reel to Stories.
